Software Requirement Specification (SRS)

Functional Requirements: Manage Room Type & Manage Room Modules

MODULE 1: MANAGE ROOM TYPE
Manage Room Type Screen
UC Code UC-001 UC Name Manage Room Type
Actor Manager
Description Allows the manager to view room types, search room types by keyword, filter room types by status or capacity, and review room type configurations for inventory management.
Trigger Event Manager opens Room Type Management.
Preconditions
  • Manager is authenticated and authorized.
  • Room type records may exist in the system.
Main Flow
No. Performed by Action
1 Manager Opens Room Type Management.
2 System Loads room type statistics such as total room types and active room counts.
3 System Displays room type list with code, name, base price, max capacity, and status.
4 Manager Searches by keyword or filters room types by capacity or status.
5 System Updates the room type list according to the filter.
Alternative Flow
No. Performed by Action
2a System If no room type exists, the system displays an empty-state message.
4a Manager Manager clears filters to view all room type records.
Postconditions Manager can review room type details and select room types for editing or status modification.
Create Room Type Screen
UC Code UC-002 UC Name Create Room Type
Actor Manager
Description Allows the manager to create a new room type by providing code, name, base price per night, guest capacity, amenities, and description.
Trigger Event Manager clicks the "Add New Room Type" button on Room Type Management screen.
Preconditions
  • Manager is authenticated and authorized.
  • Manager is on Room Type Management screen.
Main Flow
No. Performed by Action
1 Manager Clicks "Add New Room Type" button.
2 System Displays Create Room Type form with fields: Code, Name, Base Price, Max Adults, Max Children, Amenities, Description.
3 Manager Fills in required room type details and submits form.
4 System Validates input data (uniqueness of code/name, positive price and capacity values).
5 System Saves new room type record with default status "Active" and displays success notification.
Alternative Flow
No. Performed by Action
4a System If input validation fails (e.g. duplicate code, negative price), system displays validation error messages.
3a Manager Manager clicks "Cancel" button; system discards inputs and returns to Room Type list.
Postconditions A new room type is saved in the system and becomes available for room creation and room pricing configuration.
Update Room Type Screen
UC Code UC-003 UC Name Update Room Type
Actor Manager
Description Allows the manager to edit existing room type information including base price, capacity, amenities list, and description.
Trigger Event Manager clicks "Edit" action button on a room type record.
Preconditions
  • Manager is authenticated and authorized.
  • Selected room type record exists in the system.
Main Flow
No. Performed by Action
1 Manager Clicks "Edit" button next to a room type.
2 System Fetches room type details and loads them into the update form.
3 Manager Modifies desired fields (e.g. Base Price, Capacity, Amenities) and submits form.
4 System Validates updated data.
5 System Updates room type record in database and displays success notification.
Alternative Flow
No. Performed by Action
4a System If validation fails, system highlights invalid fields with error messages.
3a Manager Manager cancels editing; system discards changes and restores original values.
Postconditions Room type record is updated; future room assignments and booking calculations reflect new configurations.
Change Room Type Status Screen
UC Code UC-004 UC Name Change Room Type Status
Actor Manager
Description Allows the manager to activate or deactivate a room type to control whether rooms of this type can be booked or assigned.
Trigger Event Manager toggles status switch or clicks "Deactivate/Activate" on a room type.
Preconditions
  • Manager is authenticated and authorized.
  • Room type record exists in the system.
Main Flow
No. Performed by Action
1 Manager Clicks status toggle button for a specific room type.
2 System Checks if active rooms or upcoming bookings are linked to this room type.
3 System Displays a confirmation prompt asking manager to confirm status change.
4 Manager Confirms status update action.
5 System Updates room type status (Active <-> Inactive) and refreshes display list.
Alternative Flow
No. Performed by Action
2a System If active bookings exist for this room type, system displays a warning regarding existing reservations.
4a Manager Manager cancels confirmation dialog; status remains unchanged.
Postconditions Room type status is updated, enabling or restricting future bookings and room creation.
MODULE 2: MANAGE ROOM
Manage Room List Screen
UC Code UC-005 UC Name Manage Room List
Actor Manager
Description Allows the manager to view room inventory, search rooms by room number, filter rooms by room type, floor, or status (Available, Occupied, Maintenance, Dirty), and review room operations.
Trigger Event Manager opens Room Management screen.
Preconditions
  • Manager is authenticated and authorized.
  • Room records exist in the system.
Main Flow
No. Performed by Action
1 Manager Opens Room Management screen.
2 System Loads room summary metrics (Total Rooms, Available, Occupied, Out of Order).
3 System Displays room list with Room Number, Room Type, Floor, Price, and Operational Status.
4 Manager Searches by Room Number or filters by Floor, Room Type, or Status.
5 System Updates displayed room list according to selected criteria.
Alternative Flow
No. Performed by Action
2a System If no room matches filter criteria, system displays an empty-state message.
4a Manager Manager clears filters to view all room inventory records.
Postconditions Manager can inspect room status, perform room creation, or trigger room editing/maintenance flow.
Add New Room Screen
UC Code UC-006 UC Name Add New Room
Actor Manager
Description Allows the manager to register a new physical room into system inventory, assigning it to a Room Type, Floor number, and initial operational status.
Trigger Event Manager clicks "Add New Room" button on Room Management screen.
Preconditions
  • Manager is authenticated and authorized.
  • At least one Active Room Type exists in the system.
Main Flow
No. Performed by Action
1 Manager Clicks "Add New Room" button.
2 System Displays Add Room form with dropdown of active room types and floor selections.
3 Manager Inputs Room Number, selects Room Type, Floor, enters notes, and submits form.
4 System Validates uniqueness of Room Number and completeness of required selections.
5 System Saves new room record with initial status "Available" and displays success notification.
Alternative Flow
No. Performed by Action
4a System If Room Number already exists, system displays "Room Number already exists" error message.
3a Manager Manager cancels operation; system discards inputs and returns to Room List.
Postconditions New room is registered in inventory and becomes available for room assignment during check-in.
Update Room Information Screen
UC Code UC-007 UC Name Update Room Information
Actor Manager
Description Allows the manager to edit existing room details, such as assigned Room Type, Floor number, or room notes.
Trigger Event Manager clicks "Edit" on a specific room row.
Preconditions
  • Manager is authenticated and authorized.
  • Selected room record exists in the system.
Main Flow
No. Performed by Action
1 Manager Clicks "Edit" button next to a room.
2 System Fetches room details and populates edit form fields.
3 Manager Modifies desired room details (e.g. Floor, Room Type, Notes) and clicks Save.
4 System Validates updated data.
5 System Saves updated room details and shows success confirmation.
Alternative Flow
No. Performed by Action
3a System If room is currently Occupied, system restricts changing Room Type and displays notification.
4a Manager Manager cancels edit; system restores original room details.
Postconditions Room attributes are updated in system records.
Change Room Operational Status Screen
UC Code UC-008 UC Name Change Room Operational Status
Actor Manager
Description Allows the manager to manually set a room's operational status (e.g. mark as Maintenance / Out of Order, or return it to Available) with reason notes.
Trigger Event Manager selects a room and clicks "Change Operational Status".
Preconditions
  • Manager is authenticated and authorized.
  • Selected room record exists in the system.
Main Flow
No. Performed by Action
1 Manager Selects room and chooses target operational status (e.g. Maintenance).
2 System Checks current room state (ensures room is not currently Occupied).
3 Manager Enters reason note for maintenance/out-of-order and confirms status update.
4 System Saves new operational status and logs maintenance notes.
5 System Updates room status indicator on Room Status Board and Room Management list.
Alternative Flow
No. Performed by Action
2a System If room is currently Occupied, system displays an error alert preventing status change until check-out or room re-assignment.
3a Manager Manager cancels status change modal; status remains unchanged.
Postconditions Room status is updated, enabling or temporarily excluding room from check-in availability.
